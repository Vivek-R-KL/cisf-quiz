1. Connect to GitHub

Repository is fixed to Vivek-R-KL/cisf-quiz (main). Just paste your access token below.

2. Choose Question Paper

To create a brand-new quiz paper, pick an existing paper above to use as the template, then click "Copy as New Paper" — you'll be asked for a new file name, whether to start blank, and (if blank) how many questions it should have, so the exam's question palette is sized correctly right away. "Delete Quiz Paper" permanently removes the selected paper from GitHub.
