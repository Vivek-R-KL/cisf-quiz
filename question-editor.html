📝 Question Editing

← Back to Admin Dashboard

1. Connect to GitHub

Set this up once. It is saved on this device only. You need a GitHub Personal Access Token with write access to the repository where your quiz files are hosted (Settings → Developer settings → Fine-grained tokens → grant "Contents: Read and write" for this repository).

2. Choose the Question Paper to Edit

3. Edit Questions

Click a bubble (A, B, C, D) to mark it as the correct answer. Changes are only saved to GitHub when you press "Save Changes to GitHub" below.
