📝 Question Editing

← Back to Admin Dashboard

1. Connect to GitHub

Repository is fixed to Vivek-R-KL/cisf-quiz (main). Just paste your access token below.

2. Choose Question Paper

To create a brand-new quiz paper, pick an existing paper above to use as the template, then click "Copy as New Paper" — you'll be asked for a new file name and whether to start with no questions. "Delete Quiz Paper" permanently removes the selected paper from GitHub.

⚙️ Quiz Settings & Metadata

3. Edit Questions

Click bubble (A, B, C, D) to set correct answer. Use "Paste Options" to paste 4 options copied from Excel, "Translate" to auto-fill Hindi for one question, "Import Questions from Excel" to bulk-load English questions from the template file, and "Translate All to Hindi" to fill in every missing Hindi field at once.
