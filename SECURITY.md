# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest (main branch) | :white_check_mark: |
| older releases        | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please **do not open a public issue**. Instead, report it privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting** (preferred): Go to the **Security** tab of this repository and click **"Report a vulnerability"**.
2. **Email**: Send details to **[vvkngz@gmail.com]** with a clear description of the issue and steps to reproduce it.

Please include as much of the following information as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue (proof-of-concept, if available)
- Affected version(s) or commit hash
- Any suggested fix or mitigation, if known

## What to Expect

- We will acknowledge your report within **3 business days**.
- We will investigate and aim to provide an initial assessment within **7 business days**.
- Once confirmed, we will work on a fix and coordinate a release timeline with you.
- We will credit reporters (if desired) once the issue is resolved, unless you prefer to remain anonymous.

## Scope

This policy applies to code and configuration within this repository. It does not cover:

- Third-party dependencies (please report those to their respective maintainers, or check our Dependabot alerts)
- Issues arising from unofficial forks or modified versions of this project

## Disclosure Policy

We follow a coordinated disclosure process. Please give us reasonable time to address the issue before publicly disclosing it. We aim to resolve critical vulnerabilities within 30 days of confirmation.

Thank you for helping keep this project and its users safe.
